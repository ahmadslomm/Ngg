The original shipped **81 Android activities** and **32 live H5 pages**. The
rebuild has **22 screens**. Activity count is not directly comparable (one Flutter
screen can replace several activities, and some activities are dialogs), so no percentage is
asserted here — see the parity report for per-system figures.

## Known client gaps

- **14 server events have no handler** (see the socket map).
- **Storage keys: 1** — `fcm_device_token`. The original's
  SharedPreferences surface is far larger (148 `waitio_*` tokens in the
  decrypted strings, though not all are storage keys).
- **No offline/connectivity handling** was found.
- **The Flutter test toolchain does not run in this environment** — `flutter_test` fails to compile
  across all three installed SDKs. No client test has ever executed here, so every client claim in
  this project rests on static analysis alone.
